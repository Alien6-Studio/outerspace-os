# OuterSpace OS by Alien6

OuterSpace OS is a distribution project by [Alien6](https://alien6.com), focused
on a small, purpose-built host for Kubernetes inference workers.

The visual identity retains its original planetary illustration and pink/violet
palette. The faceted orbital mark and ASCII boot banner connect the website with
the operating system. The footer follows the same “by Alien6” attribution used by
[Trunx](https://trunx.io), [Signal](https://code-signal.app) and
[Ruleflow](https://ruleflow.sh).

Development happens in the [GitHub repository](https://github.com/Alien6-Studio/outerspace-os).
The distribution source lives on `main`; website source and generated pages live
on `gh-pages`. Project source licensing must be finalized before public release;
Ubuntu packages and bundled upstream components retain their own licenses.
