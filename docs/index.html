03 / SMALLER SURFACE. CLEARER CONTROL.

Deliberate by default.

01

A read-only foundation

dm-verity protects the root filesystem against corruption. Signed boot and transactional A/B updates are required before stable.

02

eBPF where it counts

A Cilium profile for cluster networking and policy, with BPF and BTF checked in the image kernel. Local cross-node allow/deny tests pass.

03

Space with a lifecycle

Kubelet owns unused-image cleanup: 24-hour maximum age and disk-pressure thresholds. Dragonfly has its own six-hour cache TTL.

04

Security that earns its claims

CIS Ubuntu Level 1 Server is the target. Audit evidence, documented tailoring and vulnerability review are release gates. No certification claimed.
